# 🧠 Bilderkennung KI

Eine moderne Webanwendung mit Streamlit und Python. Die Anwendung bietet eine übersichtliche Benutzeroberfläche zum Hochladen und Anzeigen von Bildern.

## 🚀 Funktionen

- Modernes, dunkles Design
- Deutsche Benutzeroberfläche
- Bild-Upload
- Vorschau hochgeladener Bilder
- Separater Bereich für Analyseergebnisse
- Navigation zwischen verschiedenen Seiten

## 🛠️ Verwendete Technologien

- Python
- Streamlit
- Pillow
- HTML und CSS

## 📂 Projektstruktur

```text
bilderkennung-ki/
│
├── app.py
├── requirements.txt
└── README.md
```

## 💻 Installation

Repository herunterladen oder klonen:

```bash
git clone DEINE-GITHUB-REPOSITORY-URL
```

In den Projektordner wechseln:

```bash
cd bilderkennung-ki
```

Benötigte Bibliotheken installieren:

```bash
pip install -r requirements.txt
```

## ▶️ Anwendung starten

```bash
streamlit run app.py
```

Die Anwendung ist anschließend normalerweise unter folgender Adresse erreichbar:

`http://localhost:8501`

## ☁️ Online veröffentlichen

Die Anwendung kann über Streamlit Community Cloud veröffentlicht werden:

https://share.streamlit.io/

Dazu das GitHub-Repository verbinden und `app.py` als Hauptdatei auswählen.
